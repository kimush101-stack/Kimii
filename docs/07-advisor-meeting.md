# פגישת מיקוד — יועץ עסקי ומשווק

*משך מוצע: 90 דקות. לשלוח את [מסמך הקונספט](01-concept.md) ואת המסמך הזה יומיים לפני.*

## מטרת הפגישה

לצאת עם **החלטות** (לא רק רעיונות) על 6 השאלות הפתוחות, ועם תוכנית 90 יום שיש בה אחראי/ת ותקציב לכל שורה.

## מה להביא

- תוצאות הפיילוט ([טופס תצפית](05-pilot-feedback.md) ממולא)
- מדדי 3 השבועות הראשונים של הסרטונים
- תמונות של התלבושת והלוגו הנוכחיים
- טיוטת [הצעת המופע](06-show-offer.md)

## סדר יום

| זמן | נושא | שאלה להחלטה | החלטה |
|---|---|---|---|
| 0–10 | עדכון | מה למדנו מהפיילוט ומהסרטונים? | |
| 10–25 | קהל | גיל יעד מדויק? איך מדברים לילדים בתוכן ולהורים בשיווק? | |
| 25–40 | מותג | שם סופי, שם משתמש, דומיין, סימן מסחר, בידול חזותי | |
| 40–55 | מודל הכנסות ותמחור | מה המוצר הראשון שמוכרים? כמה עולה? מה העלות שלנו (ציוד, נסיעות, ביטוח, אישורים)? | |
| 55–70 | לקוח ראשון | איזה ערוץ תוקפים קודם — ימי הולדת, גנים או קייטנות? איך נראה תהליך הזמנה? | |
| 70–85 | תקציב ו־90 יום | תקציב לתלבושת, צילום, עריכה וקידום ממומן; מילוי [שלד 90 יום](04-launch-checklist.md#שלד-ל־90-יום-ימולא-בפגישת-המיקוד) | |
| 85–90 | סיכום | מי עושה מה עד מתי | |

## שאלות שכדאי לשאול את היועץ

- איזה מבנה עסקי מתאים להתחלה (עוסק פטור/מורשה)?
- איזה ביטוח נדרש להפעלת ילדים (צד ג׳)? האם מוסדות דורשים אישורים מיוחדים?
- איך מתמחרים מופע ראשון בלי לקבע מחיר נמוך מדי?

## שאלות שכדאי לשאול את המשווק

- איזו פלטפורמה ראשית — אינסטגרם, טיקטוק או יוטיוב שורטס? (קהל ההורים ≠ קהל הילדים)
- איך מגיעים למקבלי החלטות במוסדות (גננות, רכזות קייטנות, מתנ״סים)?
- מתי נכון להתחיל קידום ממומן, ובאיזה תקציב ניסוי?
