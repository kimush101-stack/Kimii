# קים משחקים 🟡🟠

> **״עם קים — כולם משחקים!״**

מאגר העבודה של מיזם **״קים משחקים״** — דמות כוכבת ילדים אנרגטית, צבעונית וספורטיבית שמובילה ילדים למשחק, תנועה, צחוק והשתתפות פעילה.
יוצרת ומבצעת: **קים נידם**.

המאגר הופך את מסמך הקונספט לחומרי עבודה מעשיים — מוכנים לשימוש בפיילוט, בצילומים ובפגישה עם היועץ העסקי והמשווק.

## מה יש כאן

### המערכת: ״המסלול של קים״

[system/index.html](system/index.html) היא מערכת צעד־אחר־צעד: 70 צעדים ב־10 שלבים, מא׳ (יסודות) ועד י׳ (הרחבה). היא מראה תמיד את הצעד הבא, עם פעולות לסימון, זמן משוער, עלות, ״תדעי שסיימת כש...״ וקישורים לחומרים.

- התוכן של המסלול נמצא ב־[system/roadmap.json](system/roadmap.json). אחרי עריכה מריצים `python3 system/build.py` (דורש `pip install markdown`).
- הבנייה מייצרת גם את [docs/04-launch-checklist.md](docs/04-launch-checklist.md), גרסה להדפסה.

1. לצלם **סרטון פיילוט אחד** — תסריט ההיכרות מוכן ב־[docs/03-video-scripts.md](docs/03-video-scripts.md).

## הערות חשובות

- המסמכים הם **טיוטות עבודה**. מחירים, גילאים ואזורי פעילות מסומנים כ־`[להשלמה]` — הם ייקבעו לפי הפיילוט והפגישה, לא הומצאו כאן.
- נוסח אישור הצילום הוא טיוטה בלבד ומומלץ לעבור עליו עם עורך/ת דין לפני שימוש.
- לפני השקעה משמעותית: לבדוק זמינות שם, דומיין, שמות משתמש ברשתות וסימן מסחר.
