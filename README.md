# קים משחקים 🟡🟠

> **״עם קים — כולם משחקים!״**

מאגר העבודה של מיזם **״קים משחקים״** — דמות כוכבת ילדים אנרגטית, צבעונית וספורטיבית שמובילה ילדים למשחק, תנועה, צחוק והשתתפות פעילה.
יוצרת ומבצעת: **קים נידם**.

המאגר הופך את מסמך הקונספט לחומרי עבודה מעשיים — מוכנים לשימוש בפיילוט, בצילומים ובפגישה עם היועץ העסקי והמשווק.

## הערות חשובות

- המסמכים הם **טיוטות עבודה**. מחירים, גילאים ואזורי פעילות מסומנים כ־`[להשלמה]` — הם ייקבעו לפי הפיילוט והפגישה, לא הומצאו כאן.
- נוסח אישור הצילום הוא טיוטה בלבד ומומלץ לעבור עליו עם עורך/ת דין לפני שימוש.
- לפני השקעה משמעותית: לבדוק זמינות שם, דומיין, שמות משתמש ברשתות וסימן מסחר.
